LAYER 01 — INPUT SANITISATIONACTIVE

First gate. Every request is scanned before any ML model processes it.

→
Regex pattern scanner — 15+ known injection & zero-day signatures
→
Perplexity filter — character entropy proxy. High entropy = obfuscated text
→
Input normalisation — unicode normalisation, whitespace collapsing, encoding checks
perplexity > 150 → FLAG  |  pattern match → escalate to BLOCK
LAYER 02 — EMBEDDING ANOMALYACTIVE

ML-based semantic analysis. Understands intent, not just surface patterns.

→
DeBERTa-v3-base — 86M param transformer fine-tuned on injection datasets
→
Variational Autoencoder — reconstruction error = anomaly score for zero-day patterns
→
Keyword feature extractor — 30+ weighted security tokens with confidence scoring
DeBERTa > 0.50 → injection FLAG  |  VAE error > 2.5 → zero-day FLAG
LAYER 03 — ENSEMBLE ENGINEACTIVE

Fuses all signals into one threat score. Core of the framework.

→
XGBoost meta-learner — 8-feature weighted ensemble. 300 estimators, max_depth=6
→
GNN session graph — models API call sequences as graph nodes to catch behavioural anomalies
→
MITRE ATT&CK mapping — every detected threat tagged to ATT&CK technique ID
score > 0.75 → BLOCK  |  0.45–0.75 → FLAG  |  < 0.45 → PASS
LAYER 04 — POLICY ENFORCEMENTACTIVE

Dual-LLM architecture reduces false positives before any action is taken.

→
Primary LLM — renders initial verdict: BLOCK / FLAG / PASS
→
Verifier LLM — independent second opinion; can override to reduce false positives
→
Policy engine — applies action: terminate, quarantine, or forward to LLM
BLOCK → terminate + log + alert  |  FLAG → quarantine + review queue
LAYER 05 — OUTPUT VALIDATION & AUDITACTIVE
Output sanitisation

LLM responses are scanned for PII leakage, prompt echoing, and policy violations before delivery to the end user.

Audit logging

Every request — input hash, all 5 layer scores, final verdict, latency — written to ELK stack with 90-day retention.

Feedback loop

Human-reviewed corrections are fed back to retrain DeBERTa and update XGBoost features in the next training cycle.
